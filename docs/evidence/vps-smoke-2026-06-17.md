## Fixes from this smoke

1. `manifest_kind` now recognizes extensionless HLS/DASH endpoints whose final
   path segment is `m3u8` or `mpd`, such as Youku
   `/playlist/m3u8?vid=...`.
2. Video jobs with a selected companion audio candidate no longer process that
   audio candidate as a standalone primary video attempt. Primary attempts stay
   on video/manifest candidates and still keep all candidates available for
   companion audio lookup.
3. Downloaded video-only candidates can download a same-family companion audio
   candidate and mux both inputs into the output MP4.
4. Dual-input video/audio MP4 output now transcodes to H.264/AAC instead of
   copy-remuxing HEVC into MP4.
5. The browser sidecar clears stale Chromium `SingletonLock`,
   `SingletonSocket`, and `SingletonCookie` files before opening a profile
   when the lock is provably stale in a Linux container or points to a dead
   local pid. This fixes Docker rebuilds that otherwise return browser probe
   HTTP 500 after a container hostname change.
